Public-key identity, content integrity, self-custody, peer-to-peer replication, local-first collaboration, and privacy as a protocol property all belong to the same lineage. Neighbourhoods is one delivery of that lineage for groups that need to coordinate, not only transact or publish.

The framework does not use global consensus for everyday replication. It keeps coordination state local-first and convergent, reserving settlement tools for the contexts where global ordering is the right instrument.

## Different problems, different tools

CRDT-replicated coordination state does not need the same machinery as global settlement. A space roster, collaborative document, mutual-aid request, or governance state can converge through local-first replication. Value transfer and inter-community settlement can use NHT and related on-chain infrastructure where appropriate.

That separation prevents token mechanics from swallowing the whole system.

## Where Neighbourhoods complements the ecosystem

Neighbourhoods can bridge with identity standards, local-first tools, relays, dWeb protocols, and blockchain settlement layers. The distinct contribution is the grammar layer: a typed, executable way for communities to define coordination patterns that can run across technical environments.

## What we want to build with you

Better identity recovery, privacy-preserving credentials, relay and routing models, space policy vectors, cryptographic proofs, developer tooling, and community-owned value flow all need people who understand the distributed web beyond slogans.
